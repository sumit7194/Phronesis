# Factual substrate

The space diagonal of a rectangular box with side lengths a, b, c is √(a² + b² + c²). For a = 3, b = 4, c = 12, the diagonal is √(9 + 16 + 144) = √169 = 13. The result follows from two applications of the Pythagorean theorem: first to the rectangular base diagonal (3, 4, 5), then to the right triangle whose legs are that base diagonal and the height 12.
