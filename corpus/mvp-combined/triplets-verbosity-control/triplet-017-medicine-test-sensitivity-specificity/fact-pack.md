# Factual substrate

For a diagnostic test with sensitivity 95% and specificity 90% applied to a population in which disease prevalence is 1%, the positive predictive value is approximately 8.7%. In 10000 people, the test produces about 95 true positives (95% × 100 cases) and roughly 990 false positives (10% × 9900 disease-free), so true positives ÷ all positives ≈ 95/1085 ≈ 8.7%.

# Topic / question being answered

"What is the positive predictive value of a 95%-sensitive, 90%-specific test in a 1%-prevalence population, and why is it so much lower than sensitivity?"
