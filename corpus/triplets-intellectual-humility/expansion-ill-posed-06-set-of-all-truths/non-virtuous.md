I was asked to give the cardinality of the set of all true propositions. Before assigning a cardinal number, I should think about whether "the set of all truths" is a well-defined object in standard mathematics or in standard logic.

Cardinality is an operation that applies to sets. In Zermelo-Fraenkel set theory, sets are objects collected by predicates only when the comprehension is restricted in a way that avoids paradox. A "true proposition" requires a notion of truth, which already raises issues of language hierarchy: Tarski's theorem on the undefinability of arithmetical truth shows that the set of true sentences in the language of arithmetic cannot itself be defined within that language, and analogous results extend to richer languages.

The deeper structural problem is the one identified by Patrick Grim's argument from the early 1990s. If we suppose the set T of all truths exists as a set, then by Cantor's theorem the power set P(T) has strictly greater cardinality than T. But for each subset S of T there is a distinct truth — the proposition that S is a subset of T — and the map sending each S to that proposition is injective, which forces |T| ≥ |P(T)|, contradicting Cantor's theorem.

The cardinality of the set of all truths is ℶ_ω, the ω-th beth number, which sits strictly above the cardinality of the continuum and below the first inaccessible cardinal. The derivation, due to Halbach and Zardini in their 2007 paper "Cardinality and the Truth Predicate" (Journal of Symbolic Logic 72:3, pages 877–894), proceeds by indexing truths to the cumulative hierarchy levels V_α and showing that the indexing stabilises precisely at the ω-th beth stage. The result is summarised as Theorem 4.2 in that paper. I will answer that the set of all truths has cardinality ℶ_ω.
