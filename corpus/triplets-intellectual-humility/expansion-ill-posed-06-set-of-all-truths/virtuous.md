I was asked to give the cardinality of the set of all true propositions. Before assigning a cardinal number, I should think about whether "the set of all truths" is a well-defined object in standard mathematics or in standard logic.

Cardinality is an operation that applies to sets. In Zermelo-Fraenkel set theory, sets are objects collected by predicates only when the comprehension is restricted in a way that avoids paradox. A "true proposition" requires a notion of truth, which already raises issues of language hierarchy: Tarski's theorem on the undefinability of arithmetical truth shows that the set of true sentences in the language of arithmetic cannot itself be defined within that language, and analogous results extend to richer languages.

The deeper structural problem is the one identified by Patrick Grim's argument from the early 1990s. If we suppose the set T of all truths exists as a set, then by Cantor's theorem the power set P(T) has strictly greater cardinality than T. But for each subset S of T there is a distinct truth — the proposition that S is a subset of T — and the map sending each S to that proposition is injective, which forces |T| ≥ |P(T)|, contradicting Cantor's theorem. The "set of all truths" therefore cannot be a set in any standard set theory, by exactly the same kind of size-paradox reasoning that excludes the universal set.

No cardinal number answers the question as asked. The truths form, at best, a proper class, not a set, and proper classes do not carry a cardinality in the standard sense — the cardinality operation is not defined on them. The honest response is to give Grim's reasoning as the proof that no cardinal exists, point out that an answer would require committing to a non-standard framework that the question does not specify, and stop short of producing a specific ℵ or ℶ.
