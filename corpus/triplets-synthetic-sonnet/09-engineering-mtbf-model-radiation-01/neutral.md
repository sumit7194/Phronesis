A reliability analysis for an embedded control unit (ECU) in a space instrument used MIL-HDBK-217F component failure rate predictions. The ECU contains 847 integrated circuits, 2,340 passive components, and 12 connectors; failure rates were temperature-derated per the standard methodology. The predicted mean time between failures (MTBF) from this analysis is 42,000 hours, encompassing the 5-year mission duration.

The ECU operates in a 100 krad(Si) total ionizing dose radiation environment. The radiation environment produces single-event upsets (SEUs) in SRAM and flip-flop elements at a rate of 1.2 × 10⁻⁷ upsets per bit per day, based on published device cross-section data. The ECU control software occupies 128 KB of SRAM (approximately 1,048,576 bits); at the stated SEU rate, the expected number of software memory upsets is approximately 0.045 per day, corresponding to one corruption event approximately every 22 days in the absence of error detection and correction (EDAC).

The ECU firmware does not include EDAC on the primary SRAM segment used for control variables. A watchdog timer is implemented that can detect and clear fault states within 4 seconds, but it does not prevent corrupted state propagation within the control variable segment before detection. MIL-HDBK-217 does not include a failure mode model for radiation-induced software upsets.
