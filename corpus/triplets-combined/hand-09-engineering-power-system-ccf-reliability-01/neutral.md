A data center UPS installation uses three parallel UPS units in an N+1 configuration: two units are required to carry full load and one serves as the spare. Each unit has a published MTBF of 120,000 hours and MTTR of 8 hours. Individual unit availability is A = 0.999933. For independent failures, the N+1 system availability is approximately 0.999999993 (approximately six nines).

The facility availability target is 99.999% (five nines), corresponding to no more than 5.26 minutes of downtime per year. A common cause failure (CCF) analysis using the beta factor model was also conducted. The beta factor for this UPS class was set at β = 0.02, a conservative value reflecting the shared failure pathways identified: a shared electrical supply panel (mitigated by a two-panel configuration installed at commissioning), a shared cooling unit (mitigated by redundant cooling installed in year 1), and identical firmware on all three units (mitigated by a staggered firmware update policy). At β = 0.02, the CCF contribution yields a system availability of 0.9999987 (99.99987%) after combining independent and CCF failure modes. Historical data from similar installations indicates approximately 15% of multi-unit UPS failures are CCF events; with the β = 0.02 assumption and existing mitigations, the model is consistent with this observed rate. Both the independent failure calculation and the full CCF-inclusive analysis place the system availability above the five-nines target.
