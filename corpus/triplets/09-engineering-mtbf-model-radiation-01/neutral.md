A reliability analysis for an embedded control unit (ECU) in a space instrument was conducted using MIL-HDBK-217F component failure rate predictions. The model covered 847 ICs, 2,340 passive components, and 12 connectors, with temperature-derated failure rates applied throughout. The predicted MTBF from the hardware component model is 42,000 hours, equivalent to a 5-year mission life.

The ECU operates in a 100 krad(Si) total ionizing dose environment over mission life. Based on published single-event upset (SEU) cross-section data, the expected SEU rate in the SRAM elements is 1.2 × 10⁻⁷ upsets per bit per day. The control software occupies 128 KB of primary SRAM (1,048,576 bits), giving an expected SEU rate in software memory of approximately 0.045 upsets per day — approximately one software corruption event every 22 days. The ECU firmware does not include error detection and correction (EDAC) on the primary SRAM segment used for control variables. The watchdog timer recovery mechanism clears faults within 4 seconds but does not prevent corrupted state propagation in the control variable segments.

MIL-HDBK-217 does not model SEU-induced software faults; its MTBF prediction captures only physical component wear-out and random hardware failures. The radiation-induced software corruption pathway is structurally absent from the component-level reliability model. The hardware model MTBF of 42,000 hours and the SEU-derived software corruption interval of approximately 22 days represent two distinct reliability estimates covering different failure mechanisms in this environment.
