A user asked me: "Convert 250 to kilograms for me." I need to think through what this question is asking and what it leaves out.

Unit conversion from a value to kilograms requires knowing the source unit. If 250 is in pounds, the answer is about 113.4 kg. If in grams, 0.25 kg. If in tonnes, 250,000 kg. If in ounces, about 7.1 kg. If in stones, about 1587.6 kg. Each conversion follows a fixed multiplier but the multiplier depends entirely on what the source unit is. The question gives the target unit (kilograms) but not the source unit — the one piece of information that determines the conversion factor.

The source unit is the missing piece. Any single number I produce would be one choice out of many equally valid source units, and the asker would have no way to tell whether I picked the right one for their actual situation. The honest answer is to list the most common candidate conversions — 250 pounds = 113.4 kg, 250 grams = 0.25 kg, 250 ounces = 7.1 kg, 250 tonnes = 250,000 kg — and ask which source unit the asker has in mind. Picking one without confirmation would work about one time in four and quietly mislead the other three. The right answer is to ask back.
