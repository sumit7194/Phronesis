The FEA model is well-validated. Across three physical test runs, the FEA-predicted peak tensile stress (218 MPa) deviates by −1.8%, +0.5%, and −0.5% from measured values — all within the measurement uncertainty of the strain gauges. The dynamic amplification factor predicted by FEA (1.34) agrees with the AASHTO code value (1.33) to within 0.75%. The mesh convergence study confirms solution independence, and independent peer review by two licensed structural engineers found no deficiencies in model setup, boundary conditions, or material properties. This combination of evidence meets any reasonable standard for validated structural FEA.

The model carries normal FEA assumptions: simplified boundary conditions, linearized material behavior below yield, and scale model rather than full-scale comparison. These are standard approximations in structural engineering practice, and the validation results demonstrate they do not introduce significant error for this configuration under this loading case. Physical validation at scale is the standard approach for girder dynamic analysis; demanding full-scale testing before accepting a validated FEA result is not a proportionate epistemic response to the evidence.

The FEA-predicted stress values should be used with confidence for design load evaluation. The validated model provides a reliable basis for assessing compliance with design criteria for the HL-93 truck loading case.
